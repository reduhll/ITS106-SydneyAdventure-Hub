Sydney Adventure Hub

Sydney Adventure Hub is a group website project for ITS106. It is based on a fictional business that offers outdoor activities and tours around Sydney. Visitors can explore experiences, estimate booking costs, read visitor information and prepare an enquiry.

The website is built using HTML, CSS and JavaScript. HTML provides the page structure, CSS controls the design and layout, and JavaScript handles the interactive features.

The website includes five pages:

* index.html: The home page includes an image slideshow, featured experiences and links to explore or plan a trip.
* experiences.html: Displays six experiences with prices, descriptions, duration and availability. Visitors can search, filter and sort the experiences.
* booking.html: Allows visitors to choose an experience, date, number of participants and optional extras. It calculates the estimated cost and checks the required details.
* guide.html: Provides visitor information and frequently asked questions that can be opened and closed.
* contact.html: Includes contact details, opening hours, a service area map and an enquiry form with input checking.

The css folder contains the main stylesheet. The js folder contains the JavaScript files for the website features. The img folder contains the experience images. The header and footer are shared through js/components.js to keep them consistent across all pages.

To run the website, extract the ZIP file and open the project folder in VS Code. Open index.html in a browser, or use the Live Server extension. Keep the files and folders in their original locations so the styles, images and scripts load correctly.

The forms work in the browser. They do not store information in a database, send messages automatically or take payments. The booking calculator provides an estimate only. The current contact email needs a valid domain before it can receive enquiries.
